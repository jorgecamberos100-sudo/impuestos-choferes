# MiVolante — Calculadora ISR / IVA

Calculadora web educativa para choferes de aplicaciones de transporte y entrega en México. Estima retenciones de ISR e IVA, compara el esquema de pago definitivo contra el provisional y muestra el depósito neto estimado. Todo el cálculo ocurre en el navegador: no hay backend, cuentas ni base de datos.

## Cómo correrlo

```bash
npm install
npm run dev
npm test
```

Para revisar tipos sin generar build:

```bash
npm run typecheck
```

## Leyenda

Estimación educativa con las reglas vigentes al 1 de enero de 2026. No es asesoría fiscal; confirma con un contador.
